STEP 2 — BUILD THE WEIGHTED LINE PICKER

Create this helper at the top of RudyWidget.tsx.
Every category in RUDY_LINES has two sub-arrays: rude and positive.
The picker chooses rude 70% of the time and positive 30% of the time:

const getRudyLine = (category: keyof typeof RUDY_LINES): string => {
  const cat = RUDY_LINES[category];
  const useRude = Math.random() < 0.7;
  const pool = useRude ? cat.rude : cat.positive;
  return pool[Math.floor(Math.random() * pool.length)];
};
