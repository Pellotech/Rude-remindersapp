4) Build web assets, then generate/sync Android

From your project root:

npm install
npm run build
npx cap add android   # only if android folder doesn't exist yet
npx cap sync android


If Android already exists, do:

npm run build
npx cap sync android


Why this matters: it copies your dist into the Android project and updates native plugins (same pattern as iOS).
