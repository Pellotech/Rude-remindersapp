TITLE: FIX REQUIRED FOR APPLE APP STORE REVIEW (Guideline 5.1.1 & 4.8)

1. Remove the mandatory login requirement for core functionality

Apple rejected the app because users must be able to create reminders WITHOUT creating an account.

Required changes:

Make the entire reminder creation flow available immediately after first launch, with:

No login screen

No personal info required

No account needed

The login/onboarding screen must be optional and never block core reminder functionality.

Technical instructions:

Add a boolean flag: isLoggedIn (default: false)

If isLoggedIn == false, show:

Full reminder creation UI

Full reminder list UI

Basic settings

Only require login for account-based features such as:

Cross-device sync

Cloud backup

Saving user preferences online

UI change:

Move “Login / Create Account” into a Settings or Profile tab with this text:

“Create an optional account to sync across devices.”

2. Fix Guideline 4.8 — Login Services Compliance

Apple is saying your “Login with ___ service” is not offering equivalent options.

Required changes:

If you offer ANY of these:

Sign in with Google

Sign in with Facebook

Sign in with Email

You must ALSO offer:

→ “Sign in with Apple”

This is mandatory for apps that use any third-party login provider.

Technical instructions:

Add Apple Sign-In using:

@react-native-apple/authentication


Add button:

Text: “Sign in with Apple”

Style: Apple Human Interface Guidelines compliant

Verify JWT on backend if applicable.

3. Ensure login never blocks premium purchases

RevenueCat must allow:

Viewing offerings without login

Purchasing without login

Restoring purchases without login

Required implementation:

Remove any login checks before calling:

Purchases.getOfferings();


Remove login checks before:

Purchases.purchasePackage();


Remove login checks before:

Purchases.restorePurchases();


Apple will reject apps that tie purchases to accounts unless it’s core to the function.

4. Add a “Guest Mode”

By default, the app opens in Guest Mode:

✔ Reminders fully working
✔ Local storage allowed
✔ Paywall working
✔ Subscriptions working
✔ No personal data collected
✔ Login optional

Add a simple banner or link such as:

“Create an account to sync your reminders.”

5. Update the Privacy UX

Since users can use your app without login:

Must add these:

On first launch, show a lightweight notice:

“This app does not require an account to function. Optional account creation is only for syncing across devices.”

6. Add App Store Reviewer Notes (IMPORTANT)

In App Store Connect → App Review → Notes:

Paste this:

“The app no longer requires login for reminder creation or usage. All core features are available in Guest Mode. Login is now optional and only used for sync. Apple Sign-In has been added as an equivalent login provider.”

This tells the reviewer EXACTLY what changed and prevents another rejection.
