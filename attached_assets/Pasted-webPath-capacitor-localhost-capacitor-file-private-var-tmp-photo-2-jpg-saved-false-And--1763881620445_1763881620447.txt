2️⃣ You did NOT save the image → saved:false

You must explicitly save the image using Capacitor’s Filesystem plugin.

🔥 THE FIX (100% guaranteed): Save the selected image before upload

import { Filesystem } from '@capacitor/filesystem';

async function pickImage() {
  const photo = await Camera.getPhoto({
    source: CameraSource.Photos,
    quality: 90,
    resultType: CameraResultType.Uri
  });

  // FIX: Save the temp file so it doesn't disappear
  const saved = await Filesystem.readFile({
    path: photo.path!.replace("file://", "") // remove scheme
  });

  const fileName = `image_${Date.now()}.jpg`;

  const savedFile = await Filesystem.writeFile({
    path: fileName,
    data: saved.data,
    directory: Directory.Documents
  });

  console.log("FINAL FILE TO UPLOAD:", savedFile.uri);

  return savedFile.uri;  // <---- UPLOAD THIS
}
⭐ Why this fix works
Before:
Camera plugin returns temp file → photo.path = "/tmp/.../photo-2.jpg"

You upload temp file → iOS deletes it → upload fails

After:
You read + write the photo to Documents directory

You upload the permanent file

Upload succeeds every time
