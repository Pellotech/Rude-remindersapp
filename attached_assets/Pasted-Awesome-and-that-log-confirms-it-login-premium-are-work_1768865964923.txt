1) Message to send Replit about the logout issue (copy/paste)

Problem: In the iOS Capacitor app, tapping Logout opens a browser/webview and lands on a 404 “Page Not Found”. It looks like the backend /api/logout does a redirect which breaks the in-app router.

Fix requested: For mobile, logout should be an API call that returns JSON (no redirect), and the app should navigate with wouter.

Please change /api/logout to JSON + POST:

app.post("/api/logout", (req, res) => {
  req.logout(() => {
    // If using sessions:
    req.session?.destroy?.(() => {});
    res.clearCookie("connect.sid"); // optional
    res.json({ success: true });
  });
});


Then update the client logout handler to:

call POST /api/logout

await clearAuthToken()

await queryClient.invalidateQueries({ queryKey: ["/api/auth/user"] })

navigate with wouter to /login (no window.location, no full-page redirect)

This keeps users inside the app and prevents the 404 screen.

(If they need to preserve Replit OIDC logout for web, keep that redirect only for web browsers—detect by checking req.headers.origin or a query param like ?platform=web.)

2) What else I see in the log

Those last two should not stay 401 after login if the app is passing the Bearer token consistently.

What that usually means
